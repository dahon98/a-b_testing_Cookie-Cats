# a-b_testing_Cookie-Cats
Данный проект представляет собой полноценный анализ результатов A/B-теста, проведенного в популярной мобильной игре Cookie Cats. Основная цель — оценить влияние изменения внутриигрового "ворота" (gate) на удержание и активность игроков.

[https://www.kaggle.com/static/images/datasets/cookie_cats.png](https://www.kaggle.com/datasets/yufengsui/mobile-games-ab-testing)

Описание проекта
В играх серии Cookie Cats игроки проходят уровни, и на определенном этапе (30-м уровне) появляется "ворота" (gate), которые предлагают игроку подождать или заплатить, чтобы продолжить игру. Разработчики хотят выяснить, как перенос этих ворот с 30-го на 40-й уровень повлияет на ключевые метрики игры.

Цели и гипотезы
Основная задача — провести статистический анализ и проверить три гипотезы:

Гипотеза 1 (Retention на 1-й день): Перенос ворот с 30 на 40 уровень изменит долю пользователей, вернувшихся в игру на следующий день.

H₀: Retention_1 в группах gate_30 и gate_40 равен.

H₁: Retention_1 различается.

Гипотеза 2 (Retention на 7-й день): Перенос ворот изменит долю пользователей, вернувшихся в игру через неделю.

H₀: Retention_7 в группах gate_30 и gate_40 равен.

H₁: Retention_7 различается.

Гипотеза 3 (Активность): Перенос ворот изменит среднее количество пройденных пользователем уровней (sum_gamerounds).

H₀: Среднее значение sum_gamerounds в группах gate_30 и gate_40 равно.

H₁: Среднее значение sum_gamerounds различается.


В проекте используется датасет Mobile Games A/B Testing с платформы Kaggle. Датасет содержит данные о 90,189 уникальных пользователях.

Структура данных:

userid — уникальный идентификатор пользователя.

version — версия игры, в которую играл пользователь (gate_30 — контрольная группа, gate_40 — тестовая группа).

sum_gamerounds — общее количество игровых раундов, пройденных пользователем.

retention_1 — вернулся ли пользователь в игру на 1-й день после установки (True/False).

retention_7 — вернулся ли пользователь в игру на 7-й день после установки (True/False).

Проект выполнен в Jupyter Notebook и включает в себя все ключевые этапы A/B-тестирования:

Загрузка и первичный анализ (EDA):

Импорт библиотек и загрузка данных с помощью kagglehub.

Проверка на пропуски и дубликаты.

Анализ распределений метрик, выявление сильной асимметрии и выбросов в sum_gamerounds.

Сплитование данных на контрольную (gate_30) и тестовую (gate_40) группы.

Расчет минимального детектируемого эффекта (MDE):

Для бинарных метрик (retention_1, retention_7) использован метод, основанный на z-критерии.

Для непрерывной метрики (sum_gamerounds) — метод, основанный на t-критерии.

Результат: Мощности теста достаточно для обнаружения целевого эффекта в 1 п.п. для метрик retention, но недостаточно для обнаружения 10%-го изменения в sum_gamerounds.

Валидация критерия (AA-тест):

Проведено 1000 симуляций AA-теста на контрольной группе.

Для бинарных метрик использован z-тест для пропорций, для sum_gamerounds — U-тест Манна-Уитни.

Распределение p-value проверено на равномерность с помощью гистограмм, QQ-графиков и теста Колмогорова-Смирнова. Критерии признаны корректными.

A/B-тестирование:

Для retention_1 и retention_7: применен двусторонний z-тест для пропорций.

Для sum_gamerounds: применен двусторонний U-тест Манна-Уитни (непараметрический аналог t-теста) из-за сильной асимметрии распределения данных.

Инструменты и технологии
Язык: Python 3

Библиотеки:

pandas, numpy — для обработки и анализа данных.

matplotlib, seaborn — для визуализации данных.

scipy.stats — для статистических тестов (t-тест, тест Колмогорова-Смирнова, Манна-Уитни).

statsmodels — для z-теста пропорций и расчетов мощности.

kagglehub — для загрузки датасета.

Среда: Google Colab / Jupyter Notebook.

Основные результаты и выводы
В результате проведенного анализа были получены следующие ключевые выводы:

Retention на 1-й день (retention_1):

P-value = 0.0744 (> 0.05).

Вывод: Статистически значимых различий между группами не обнаружено. Нет оснований считать, что перенос ворот повлиял на краткосрочное удержание.

Retention на 7-й день (retention_7):

P-value = 0.0016 (< 0.05).

Вывод: Обнаружено статистически значимое различие. В тестовой группе (gate_40) удержание на 7-й день оказалось ниже (18.2%), чем в контрольной (19.02%). Это говорит о негативном влиянии изменения на долгосрочное удержание пользователей.

Количество пройденных уровней (sum_gamerounds):

P-value = 0.0502 (на границе значимости).

Вывод: Статистически значимых различий на уровне α=0.05 не обнаружено. Однако из-за недостаточной мощности теста (MDE составил 12.9% при целевом эффекте 10%) нельзя однозначно утверждать об отсутствии эффекта.

Итоговое заключение:
Перенос внутриигрового "ворота" с 30-го на 40-й уровень негативно сказался на долгосрочном удержании игроков (retention_7). Влияние на краткосрочное удержание и общую активность игроков статистически не подтвердилось. На основании полученных данных, внедрение изменения не рекомендуется.
